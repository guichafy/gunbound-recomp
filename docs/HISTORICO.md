# Histórico de versões

Resumo do que entrou em cada versão, em ordem crescente. A evidência de cada entrega está
no [HANDOFF](sdd/HANDOFF.md) e nas decisões em [DECISIONS.md](sdd/DECISIONS.md). Desde a
0.20.5, várias entregas entraram no código sem mudar o número de versão. Elas aparecem
por ADR no fim da tabela.

| Versão | O que entrou |
|---|---|
| 0.1–0.2 | Partida 1×1, terreno destrutível, vento, dano, queda, fila por atraso, três dificuldades, pausa, ajuda, resultado, revanche e perfil local |
| 0.3–0.5 | Bigfoot e Mage com sprites, áudio e ataques de um pacote externo, hoje fora do escopo (ADR-132). Bigfoot com salvas T1/T2/SS. Mage com escudo, regeneração, laser, hélice e EMP |
| 0.6–0.6.4 | Arte HD, mobiles articulados, piloto no assento, tiros e impactos contínuos |
| 0.7 | Nome Gunbound Recomp, aplicativo, perfil novo e `scripts/check.sh` |
| 0.8–0.9 | Miramo Town A, câmera rolante, vento 2D, clima, Thor e partículas de chão |
| 0.10–0.12 | HUD original, popup de opções, música, busca da CPU fora do quadro, mira Slice e Drag |
| 0.13 | Onze itens de batalha, com custo de atraso, barra F1–F6 e Select Item |
| 0.14–0.14.9 | Loja, compra, inventário, oito atributos, Gold da partida, avatares HD e layout clássico 3×3 |
| 0.15 | Nak com dados do cliente original. Loja Full HD baseada no vídeo |
| 0.16 | Loja no design XFS, catálogo de 562 registros (479 compráveis) e bônus por equipamento |
| 0.17 | 550 avatares vestidos em HD, depois substituídos pelos originais na ADR-130 |
| 0.18–0.18.7 | Regras de batalha do cliente (delay, abertura, passe), auditoria da CPU, carteira de teste, revisão de qualidade e brilho do Great Devil |
| 0.19 | Elenco dos 16 mobiles do cliente, com IDs 1–3 preservados |
| 0.20 | Balística comum de 20 Hz e ponto fixo 24.8, carga de 3 s, Boomer, WaterEffect e cronologia dos 48 tiros |
| 0.20.1 | Turtle T1/T2 com água contínua e SS com seis bolhas |
| 0.20.2 | Turtle T2 com a onda nativa. Aceito pelo usuário |
| 0.20.3 | Bigfoot e Mage voltam à arte original do cliente |
| 0.20.4 | Porte parcial de tiros e animações de Bigfoot e Mage, sem resultados registrados. O Mage foi revisado depois na ADR-126 |
| 0.20.5 | ASate, JD, Aduka e Raon com efeitos próprios (ADR-094) |
| ADR-092 a 114 | Sala 1×1, lobby e sala clássicos, botões e SETTINGS com acabamento 4×. Ajustes da sala aceitos pelo usuário |
| ADR-115 | Bigfoot original suavizado 4× |
| ADR-116 a 120 | Tiros, minas e rastro do Raon |
| ADR-121 a 125 | Encaixe do piloto e combate do Aduka pelo cliente |
| ADR-126 a 129 | Mage revisado pelo cliente: combate, climas secundários e partículas. Lightning revisado (ADR-127) |
| ADR-130/131 | Avatar Shop e avatares com os quadros originais do cliente |
| ADR-132 | OpenBound (Season 2) sai do escopo: skill de porte C# removida, docs e skills citam só o cliente |
